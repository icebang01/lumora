## 1. 首帧黑闪修复（本次重点，必测）

根因：mpv `--wid` 子窗口在窗口缩放 / 载入新文件时会发多次 `vo-reconfig`，末次收敛到最终尺寸常晚于 `time-pos>0`；
旧逻辑用 `time-pos>0` 撤加载遮罩 → 遮罩撤了但底层黑帧还没出 → 可见闪。
修复：遮罩撤下门控改为「末次 `vo-reconfig` + 600ms 静默去抖」（覆盖 DWM ~200–500ms 缩放动画拖尾）；ffmpeg 引擎无 `vo-reconfig`，用 400ms 看门狗兜底。

- [ ] **冷启动双击文件**：idle → 画面是否一次平滑过渡，**无黑帧闪一下**（之前是"闪一下才播"）。
- [ ] **暂停 → 恢复**：恢复播放瞬间无黑闪。
- [ ] **拖拽改变窗口尺寸**（任意方向缩放）：缩放过程中 / 结束后无黑帧拖尾。
- [ ] **换集 / 换文件**（播放列表下一集、拖入新文件）：无黑闪。
- [ ] **ffmpeg 引擎下同样验证**：设置 → 播放引擎 切到 `ffmpeg`，重复上面 4 项，确认看门狗兜底生效、遮罩不卡死。

> 判定：四种场景均"一次到位、无可见黑闪"即合格。若仍闪，开 HUD 看 `vo-reconfig` 事件与遮罩撤下时序。

## 判定口径

- **跟手**：交互延迟 < 50ms，动画无掉帧感。
- **流畅**：真机渲染稳定 60fps、丢帧率 < 0.5%、avSync < ±40ms。
- **稳定**：30min 内存无单调增长、边缘场景不崩溃。
- **首帧无闪**：第 1 节四种场景均一次到位、无可见黑帧。
