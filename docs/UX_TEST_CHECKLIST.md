# Lumora 交互体验 & 流畅性 · 人工测试清单

> 用途：在**真实机器（有 GPU + 显示器 + 音频）**上点着测，覆盖自动化基准（`tools/ux-bench.js`）
> 测不到的"感官"项。自动化能跑的逻辑量（命令延迟 / seek 延迟 / 丢帧计数 / JS 堆）优先用
> `node tools/ux-bench.js <媒体>` 出数；本清单聚焦**需人眼/人耳判断**与**需 GPU 渲染**的项。
>
> 调试辅助：播放时按反引号 `` ` `` 开关调试 HUD（引擎 / AudioContext 状态 / 字幕 / time-pos / 事件日志）。

## 0. 启动与加载
- [ ] 冷启动到落地页（idle）时间 < 2s，无白屏/闪烁。
- [ ] 打开一个 1080p 文件：idle → 播放界面的过渡是否顺滑（无卡顿跳变）。
- [ ] 首帧出现时间：双击文件后到看到画面的耗时（主观"秒开"感）。
- [ ] 异常文件（损坏/不支持编码）：是否优雅降级而非崩溃。

## 1. 播放控制跟手度（对标 ux-bench 的 [A]）
- [ ] 空格暂停/播放：按下到画面定格/动作的体感延迟（基准应 < 50ms 为"跟手"）。
- [ ] 方向键 ←/→ 快进退：连续按是否流畅、time-pos 是否实时跟手。
- [ ] 音量滚轮/↑↓：音量条动画是否跟手、有无掉帧感。
- [ ] 倍速切换（含小数倍速）：OSD 数字变化与画面节奏是否一致。

## 2. 流畅性（画面与同步）
- [ ] **真·渲染帧率**：长时间播放画面是否稳定 60fps（无周期性卡顿）。用 HUD 或系统 FPS 叠层确认。
- [ ] **拖拽进度（长距离 seek）**：拖到任意位置，是否 < 200ms 出首帧、有无"转圈"。
- [ ] **丢帧率**：ux-bench 读 `dropped/(presented+dropped)`，真机应 < 0.5%；高码率/4K 文件单独验。
- [ ] **音画同步**：口型/动作与声音是否对齐；ux-bench 读 `avSync`，真机应 < ±40ms。
- [ ] **快进/倍速下的同步**：2×/4× 播放数分钟后 avSync 是否漂移。
- [ ] **章节跳转**：跳章节是否精准、无黑帧。

## 3. UI 与动画（对标"丝滑度"）
- [ ] OSC（控制条）淡入淡出：缓动是否自然（设计系统 `cubic-bezier(0.16,1,0.3,1)`，220–320ms）。
- [ ] 设置面板开合：毛玻璃模糊（`blur(22px) saturate(160%)`）是否顺滑、无锯齿闪烁。
- [ ] 倍速/字幕菜单弹出：定位与过渡是否跟手。
- [ ] 深色沉浸主基调 + 渐变（青→紫→粉）在各面板是否一致、无纯色块违和。
- [ ] 高 DPI（125%/150% 缩放下）：文字/图标是否清晰、布局无错位。

## 4. 字幕与弹幕
- [ ] 内嵌/外挂字幕：加载与切换是否即时，有无闪烁。
- [ ] 字幕样式（字体/大小/描边/位置）调整是否实时生效。
- [ ] 在线字幕匹配（配置 API Key 后）：弹弹/B 站源是否可用、匹配速度。
- [ ] 弹幕密度高时：是否影响播放流畅度。

## 5. 播放列表与续播
- [ ] 拖入多文件：列表加载与切换是否顺滑。
- [ ] 关闭再开：续播卡片是否出现、定位是否准确（"从此处继续"）。
- [ ] 播放结束自动下一集：过渡是否无缝。

## 6. 音频听感（必须人工试听）
- [ ] 普通播放：声画同步、无破音/爆音。
- [ ] 暂停→恢复：音频是否无缝续接（无咔哒/静默断层）。
- [ ] 倍速播放：音调是否异常（变调/失真）。
- [ ] 不同输出设备切换（扬声器/耳机/HDMI）：是否即时生效、无残留。

## 7. HDR / 色彩
- [ ] HDR10 文件：色彩/亮度是否准确（无泛白/过暗）。
- [ ] SDR 文件在 HDR 显示器上：映射是否自然。
- [ ] 去色带（descale）开关：开启后渐变是否更干净、无明显性能损耗。

## 8. 边缘场景与稳定性
- [ ] 长时间播放（>30min）：内存是否稳定（ux-bench [C] 测交互态堆增长；本项补充静置态 RSS）。
- [ ] 最小化/最大化/全屏切换：渲染是否恢复、无黑屏。
- [ ] 远程桌面 / 集显环境：是否降级为纯音频而非崩溃。
- [ ] 连续快进 5 分钟：是否出现累积延迟或卡死。

## 判定口径
- **跟手**：交互延迟 < 50ms，动画无掉帧感。
- **流畅**：真机渲染稳定 60fps、丢帧率 < 0.5%、avSync < ±40ms。
- **稳定**：30min 内存无单调增长、边缘场景不崩溃。

> 自动化与人工互补：逻辑量交给 `tools/ux-bench.js`（可进 CI）；感官量与 GPU 渲染量按本清单人工复核。
